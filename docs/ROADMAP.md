# 开发路线图（11 阶段）

每阶段交付：完整代码 + 目录 + 设计说明；收到"继续"后进入下一阶段。已完成阶段的验收标准冻结，后续阶段不得破坏。

## 阶段 1 ✅ — 地基（当前）

- 项目脚手架：Vite + TS strict，`npm install && npm run dev` 可直接运行
- ECS 核心：sparse-set SoA 存储、增量查询、固定时间步长调度器
- 核心模式：EventBus、CommandStack (Undo/Redo)、ServiceContainer (DI)、ObjectPool
- 27 个单元测试；20 万实体压力演示 @ 30Hz 模拟
- 文档：ARCHITECTURE.md / MODULES.md / ROADMAP.md

## 阶段 2 — 基础引擎

- RendererFactory：WebGPURenderer 探测 → WebGL2 回退；PBR 管线、阴影、后处理骨架（Bloom/FXAA 先行）
- RTS 摄像机：平移/缩放/旋转/倾斜、边缘滚动、平滑阻尼
- 输入系统：InputMap 抽象、指针拾取（GPU picking）
- RenderSyncSystem：ECS SoA → InstancedMesh 实例缓冲直通
- 验收：阶段 1 的 20 万实体以 instancing 渲染为可见粒子云，60 FPS

## 阶段 3 — 地图系统

- HeightField + ChunkManager 流式加载、四叉树 LOD、法线/裙边处理
- 程序化生成：噪声分层 → 山脉/丘陵/平原，河流下切、湖泊、海岸线、森林散布
- 地形编辑：Raise/Lower/Flatten/Smooth/Paint 笔刷，全部走 CommandStack（Undo/Redo）
- 水面渲染
- 验收：可编辑的无限流式地形，编辑可撤销

## 阶段 4 — 道路系统

- RoadGraph 拓扑 + 车道图；直线/曲线/Bezier 铺设、吸附、坡度校验
- 程序化 Mesh：截面挤出、交叉口缝合、环岛、高架/桥梁/隧道
- 标线、人行道、路灯、装饰；道路 LOD
- 验收：CS 手感的铺路工具链，自动生成合法路网几何

## 阶段 5 — 建筑系统

- 区划（R/C/I/Office）+ 需求驱动生长；服务建筑（学校/医院/消防/警察/公园/电厂/水厂/垃圾场/机场/港口）
- 建筑原型数据驱动 + 工厂；等级/升级/废弃生命周期
- 地价、噪音、污染、电力、水、就业、居民、税收、维护全字段建模
- 验收：区划后建筑自动生长并随条件升级

## 阶段 6 — 城市模拟

- 人口/就业/教育/健康/幸福度/犯罪/垃圾/火灾耦合模型（全部数据关联，无随机数堆砌）
- 电网（容量-负载-停电级联）、水网（供水/排污/压力）、财政（税/费/贷款/预算/波动）
- 昼夜/月/季节/天气；模拟迁入 Sim Worker；IndexedDB 存档 + 自动保存 + 版本迁移
- 验收：城市在无玩家干预下产生可解释的兴衰动态；存档往返一致

## 阶段 7 — 交通系统

- A\* / HPA\* / Flow Field（Path Worker 批处理）；拥堵成本回馈边权、动态重规划
- 单行道、变道、红绿灯、让行
- 验收：拥堵可视化真实成形，绕行行为可观察

## 阶段 8 — AI 居民

- 市民日程状态机（家↔工作↔商店↔娱乐，昼夜驱动）；车辆跟驰/停车/避让
- Agent LOD：近处全模拟、远处抽象化（保 50 万居民规模）
- 验收：跟踪任一市民可见完整的一天

## 阶段 9 — UI

- 可拖拽窗口框架 + 数据绑定；ToolBar、建筑/道路菜单、预算、Inspector、图表、MiniMap
- 交通/电力/水/污染/地价热力 Overlay，全部实时
- 验收：全部游玩功能可经 UI 操作

## 阶段 10 — 优化

- 剖析驱动：GPU 遮挡剔除（WebGPU compute）、纹理图集合批、SSAO/HDR 完整后处理
- WASM 替换证实热点（Flow Field / 侵蚀）；SAB 环形缓冲精调
- 验收：目标场景（100k 建筑/500k 居民/100k 车辆）稳定 60 FPS，附性能报告解释每项优化

## 阶段 11 — 测试

- 模拟确定性回归（同种子同操作 ⇒ 同状态哈希）、存档兼容矩阵、性能基准 CI
- 验收：`npm test` 全绿 + 基准报告
